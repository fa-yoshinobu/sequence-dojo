# 配線モード

作業盤の TB 端子台と PLC の端子を、3D 上でケーブル配線する練習モードです。
配線に応じて回路を計算するため、COM の配線忘れや電源の誤配線があると、実物と同じように動きません。

## 配線練習用 PLC

盤の奥に置く 3D の PLC の機種を、配線タブの「配線練習用 PLC」で選びます。**通信先 PLC（接続タブ）とは別に指定**できます。
たとえば「配線は検定と同じ FX5S で練習し、プログラムは手元の iQ-R や GX Simulator3 で動かす」という使い方ができます。

| 機種 | 入力端子 | 入力コモン | 出力端子 | 出力コモン | サービス電源 |
|---|---|---|---|---|---|
| FX5S-30MR/ES（既定） | X0〜X17 | S/S | Y0〜Y15 | COM0〜COM3 | 24V / 0V |
| FX5U-32MR/ES | X0〜X17 | S/S | Y0〜Y17 | COM0〜COM3（4 点ずつ） | 24V / 0V |
| Q シリーズ（QX40 + QY10） | X00〜X0F | COM | Y10〜Y1F | COM（16 点共通） | なし |
| iQ-R シリーズ（RX40C7 + RY10R2） | X00〜X0F | COM | Y10〜Y1F | COM（16 点共通） | なし |

- 端子配列は練習用に簡略化しています。実機の端子台の並びとは異なる場合があります。
- 入出力は**並び順（1〜16 点目）**で通信先のデバイスに対応します。
  例: 配線練習用 PLC が FX5S、通信先が iQ-R（入力先頭 `X0`）のとき、FX5S の端子 X10（9 点目）に配線した入力は、iQ-R の X8 に書き込まれます。
- I/O モニタには「通信先」（通信先 PLC のデバイス）と「端子」（配線練習用 PLC の端子名）を並べて表示します。
- 機種を切り替えると、切替先にも存在する端子の配線はそのまま残ります。切替先に無い端子（例: Q へ切り替えたときの COM1〜COM3、サービス電源）への配線は外れます。
- PLC 本体の上面には、入出力の状態 LED と RUN LED（通信中に点灯）があります。

## 配線の操作

| 操作 | 方法 |
|---|---|
| 配線する | 端子を 1 つクリック（緑に光る）→ 接続先の端子をクリック |
| 選択を取り消す | `Esc` |
| ケーブルを外す | ケーブルをクリックして選択 → `Delete` キー、または「選択ケーブル削除」 |
| 全部外す | 「全部外す」 |
| 標準配線を作る | 「標準配線を自動作成」（下記の 32〜35 本。機種で異なる） |
| 見やすい視点にする | 「配線ビュー」または画面下の「配線」 |

- ケーブルの両端には、盤側の端子番号を書いた札（マークチューブ）が付きます。
- ケーブルの色は自動で決まります: 赤＝+24V・入力コモン、黒＝0V・出力コモン、青＝入力、黄＝出力。
- 1 つの端子には 2 本まで配線するのが目安です（3 本以上で警告）。

## 標準配線（自動作成の内容）

| 配線 | 本数 |
|---|---|
| TB+1 → 入力コモン（S/S または COM）に盤の +24V | 1 |
| TB1〜TB16 → 入力 1〜16 点目 | 16 |
| TB− → 出力コモン（盤の 0V に。FX5 は COM0〜COM3、Q / iQ-R は COM） | 1〜4 |
| TB20〜TB33 → 出力 1〜14 点目 | 14 |

## 回路計算の規則

### 電源

- 盤内電源: TB+（+24V）と TB−（0V）。4 つずつの端子は盤内でつながっています。
- PLC サービス電源: 24V と 0V。

### 入力（シンク入力）

X*n* は、次の条件をすべて満たすと ON になります。

1. 入力コモン（FX5 は S/S、Q / iQ-R は COM）が、いずれかの電源の +24V につながっている
2. X*n* が、閉じている盤入力機器の TB 端子につながっている（入力機器の反対側は盤の 0V）
3. その電源の 0V が、盤の 0V（TB−）と同電位になっている

つまり、入力コモンを盤の +24V から取る場合は 1 本で足ります。PLC のサービス電源 24V から取る場合は、**PLC の 0V と TB− も配線**する必要があります。

### 出力（リレー出力）

盤出力機器（TB20〜TB33）は、次の条件を満たすと ON になります（機器の反対側は盤の +24V）。

- その TB 端子につながった Y*n* が ON で、かつ Y*n* の出力コモン（FX5 は COM0〜COM3、Q / iQ-R は COM）が盤の 0V（TB−）につながっている

### 短絡

次のいずれかの場合は短絡として、入出力をすべて OFF にします。

- 同じ電源の +24V と 0V が直結している
- 盤内電源とサービス電源が、+ と − を互いに入れ違いでつながれている

## 配線チェック

「配線チェック」を押すと、次の項目を調べて一覧表示します。

| 区分 | 内容 |
|---|---|
| エラー（赤） | 短絡、入力コモンに +24V が来ていない、サービス電源使用時の 0V 未接続、使用中の Y の COM が盤の 0V に未接続、1 つの TB が複数の X/Y に接続 |
| 警告（黄） | 未配線の TB 端子、1 端子に 3 本以上 |
| 参考（灰） | 標準割付と違う X/Y への接続（例: `TB7 → X10（標準割付は X6）`） |
| OK（緑） | エラー・警告が無い |

標準割付と違う接続は誤りではありません。課題で指定された割付に合わせて配線してください。

## 配線モード OFF のとき

配線モードのチェックを外すと、ケーブルは非表示になり、盤の TB*i* と PLC の X/Y が 標準割付どおりに直結されたものとして動作します。
プログラムの動作確認だけをしたいときに使います。配線したケーブルは消えず、再び ON にすると戻ります。
