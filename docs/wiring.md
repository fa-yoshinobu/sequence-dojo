# 配線モード

作業盤の TB 端子台と PLC の端子を、3D 上でケーブル配線する練習モードです。
配線に応じて回路を計算するため、COM の配線忘れや電源の誤配線があると、実物と同じように動きません。

## 配線練習用 PLC

盤の奥に置く 3D の PLC の機種を、配線タブの「配線練習用 PLC」で選びます。**通信先 PLC（接続タブ）とは別に指定**できます。
型番欄を押すと画面内に一覧が開きます。型番をクリックすると確定します。閉じた型番欄にフォーカスがあるときは、上下キーで型式と3D表示がすぐに切り替わります。一覧を開いているときは矢印キーで候補を移動し、Enterで確定します。確定すると、自動で「PLC正面拡大」のビューへ移ります。
たとえば「配線は検定と同じ FX5S で練習し、プログラムは手元の iQ-R や GX Simulator3 で動かす」という使い方ができます。

条件は **本体電源がAC100V対応（AC100～240V）、DC24V入力16点、接点出力またはDC24Vで使用できるNPNシンク出力14〜16点、I/Oがねじ止め式または差し込み式の端子台** です。DC電源本体およびEC仕様は対象外です。図面生成 `qet-io-builder` の三菱機種別JSONから取り込んでいます。

| 系列 | 選択できる本体・入出力ユニット |
|---|---|
| FX5S | FX5S-30MR/ES・30MT/ES（AC100～240V、ねじ止め） |
| FX5U | FX5U-32MR/ES・32MT/ES（AC100～240V、ねじ止め） |
| Q 入力 | QX40・QX40-S1（ねじ止め）、QX40-TS（差し込み） |
| Q 出力 | QY10・QY40P・QY50（ねじ止め）、QY10-TS・QY40P-TS（差し込み） |
| iQ-R 入力 | RX40C7・RX40PC6H（ねじ止め）、RX40C7-TS（差し込み） |
| iQ-R 出力 | RY10R2・RY40NT5P（ねじ止め）、RY10R2-TS・RY40NT5P-TS（差し込み） |

Q・iQ-Rは同一系列で、入力・出力ともねじ止め式、または入力・出力とも差し込み式の組合せだけを選びます。接続方式の混在は対象外です。QはQ61P、iQ-RはR61PでAC100Vに対応します。計18構成で、既定は従来どおり **FX5S-30MR/ES** です。通信先PLCは別設定です。

Qの表示用電源・CPUは **Q61P＋Q03UDECPU**、iQ-Rは **R61P＋R04CPU** です。電源は赤い筐体・黒い前面表示部・金属色の側板で、R61Pの黒い端子カバーも表現します。CPUは前面カバーを閉じた状態で、上部の状態表示、下部のUSBカバーとEthernetポートを描画します。これらは外観の代表構成で、通信先の型番を指定するものではありません。
PLC側のケーブル接続点は作業盤の端子と同じ高さにそろえ、支持台の高さを機種の奥行きに合わせています。

外観参照：[Q61P](https://www.mitsubishielectric.co.jp/fa/products/faspec/point.page?formNm=QnP_Q61P_1&kisyu=%2Fplcq)、[Q03UDECPU](https://www.mitsubishielectric.co.jp/fa/products/faspec/point.page?formNm=QnUDECPU_Q03UDECPU_1&kisyu=%2Fplcq)、[R61P](https://www.mitsubishielectric.co.jp/fa/products/faspec/point.page?formNm=RnP_R61P_1&kisyu=%2Fplcr)、[iQ-R CPUインタフェース](https://fa-site.mitsubishielectric.co.jp/fa/products/cnt/plcr/pmerit/cpu/cpu.html)。

- 練習盤は入力機器の片側が0V固定です。そのため、マイナスコモン専用入力（QX80/QX82、RX40NC6H/RX40NC6B等）は電圧・点数条件に合っても、この盤には直結できないため選択対象外です。PNP出力、5/12V入力、指定点数外の機種、I/Oコネクタ接続の機種も対象外です。着脱可能な端子台でも、電線をねじ止め・差し込みで接続できるものは対象です。
- 本体型番、ユニット型番、端子名、TB番号を表示します。Q/iQ-RのX/Yは入力ユニットを先頭に配置した場合のデバイス割付です。
- 「端子名・コモン対応」で接続可能な端子を一覧表示します。同じ内部回路につながる複数接点も区別して選択できます。TB番号とX/Y番号は別物です。
- 形状はメーカー正面図の寸法比・カバー・端子台・通信ポートの相対位置を反映しています。FX5S/FX5Uの上下2段と千鳥配置、Q/iQ-Rのねじ式18点と差し込み式2列を区別します。差し込み解除部はオレンジです。正面を上向きに置き、ロゴを省略した練習用モデルで、製造用CADの完全複製ではありません。
- 動作対象は先頭16入力と最大16出力（盤の負荷は14点）です。CPU電源・通信ポートは装飾表示で、電源投入手順のシミュレーションは行いません。
- FX5S-30の出力コモンは COM0=Y0〜Y3、COM1=Y4〜Y7、COM2=Y10〜Y12、COM3=Y13〜Y15 です。

- 入出力は**並び順（1〜16 点目）**で通信先のデバイスに対応します。
  例: 配線練習用 PLC が FX5S、通信先が iQ-R（入力先頭 `X0`）のとき、FX5S の端子 X10（9 点目）に配線した入力は、iQ-R の X8 に書き込まれます。
- I/O モニタには「通信先」（通信先 PLC のデバイス）と「端子」（配線練習用 PLC の端子名）を並べて表示します。
- 「シリーズ」「出力方式」「入出力の接続」で型式を絞り込めます。絞り込みだけでは現在の型式・配線は変わりません。該当なしの場合は「絞り込み解除」で一覧を戻せます。現在の型式は選択欄の下に全文表示します。
- 「PLC正面拡大」でPLCの前面を拡大します。端子にポインターを合わせると、型番・端子名・端子番号・コモンを表示します。配線モードOFFでも確認できます。
- 機種を切り替えると、切替先にも存在する端子の配線はそのまま残ります。切替先に無い端子（例: Q へ切り替えたときの COM1〜COM3、サービス電源）への配線は確認なしで外し、外した本数を表示します。
- 「型式切替の記録」には選択操作・変更前後の型式・切替エラーを最大40件記録します。ローカル保存で再読込み後も確認でき、Windows版では診断ログにも「画面操作」として残します。3Dのマウス取り込みが残った場合の解除も記録します。過去の未記録の症状の原因を遡って特定するものではありません。
- DC電源・EC仕様・接続方式混在など、対象外の型式を指定した保存ファイルは、型式と対象外の理由を表示して読込みを中止します。現在の設定・配線と元ファイルは変更しません。
- PLC 本体の上面には、入出力の状態 LED と RUN LED（通信中に点灯）があります。

## 配線の操作

| 操作 | 方法 |
|---|---|
| 配線する | 端子を 1 つクリック（緑に光る）→ 接続先の端子をクリック |
| 選択を取り消す | `Esc` |
| ケーブルを外す | ケーブルをクリックして選択 → `Delete` キー、または「選択ケーブル削除」 |
| 全部外す | 「全部外す」 |
| 標準配線を作る | 「標準配線を自動作成」（本数は機種で異なる） |
| 見やすい視点にする | 「配線ビュー」または画面下の「配線」 |

- ケーブルの両端には、盤側の端子番号を書いた札（マークチューブ）が付きます。
- ケーブルの色は自動で決まります: 赤＝+24V・入力コモン、黒＝0V・出力コモン、青＝入力、黄＝出力。
- 1 つの端子には 2 本まで配線するのが目安です（3 本以上で警告）。

## 標準配線（自動作成の内容）

| 配線 | 本数 |
|---|---|
| TB+ → 入力コモン（S/S、S/S0・S/S1 または COM）に盤の +24V | 1〜2 |
| TB1〜TB16 → 入力 1〜16 点目 | 16 |
| TB− → 出力コモン（盤の 0V に。FX5 は COM0〜COM3、Q / iQ-R は COM） | 1〜4 |
| TB20〜TB33 → 出力 1〜14 点目 | 14 |
| TB+ → 出力外部電源 +V（端子のある機種のみ） | 0〜1 |

## 回路計算の規則

### 電源

- 盤内電源: TB+（+24V）と TB−（0V）。4 つずつの端子は盤内でつながっています。
- PLC サービス電源: 24V と 0V。

### 入力（シンク入力）

X*n* は、次の条件をすべて満たすと ON になります。

1. 入力コモン（FX5 は S/S、Q / iQ-R は COM）が、いずれかの電源の +24V につながっている
2. X*n* が、閉じている盤入力機器の TB 端子につながっている（入力機器の反対側は盤の 0V）
3. その電源の 0V が、盤の 0V（TB−）と同電位になっている

つまり、入力コモンを盤の +24V から取る場合は 1 本で足ります。PLC のサービス電源 24V から取る場合は、**PLC の 0V と TB− も配線**する必要があります。

### 出力（リレー／NPNシンク出力）

盤出力機器（TB20〜TB33）は、次の条件を満たすと ON になります（機器の反対側は盤の +24V）。

- その TB 端子につながった Y*n* が ON で、かつ Y*n* の出力コモン（FX5 は COM0〜COM3、Q / iQ-R は COM）が盤の 0V（TB−）につながっている

NPN出力で外部電源 +V 端子を持つユニットは、+Vへの盤の+24Vも必要です。COMだけでは出力しません。

### 短絡

次のいずれかの場合は短絡として、入出力をすべて OFF にします。

- 同じ電源の +24V と 0V が直結している
- 盤内電源とサービス電源が、+ と − を互いに入れ違いでつながれている

## 配線チェック

「配線チェック」を押すと、次の項目を調べて一覧表示します。

| 区分 | 内容 |
|---|---|
| エラー（赤） | 短絡、入力コモンに +24V が来ていない、サービス電源使用時の 0V 未接続、使用中の Y の COM が盤の 0V に未接続、1 つの TB が複数の X/Y に接続 |
| 警告（黄） | 未配線の TB 端子、1 端子に 3 本以上 |
| 参考（灰） | 標準割付と違う X/Y への接続（例: `TB7 → X10（標準割付は X6）`） |
| OK（緑） | エラー・警告が無い |

標準割付と違う接続は誤りではありません。課題で指定された割付に合わせて配線してください。

## 配線モード OFF のとき

配線モードのチェックを外すと、ケーブルは非表示になり、盤の TB*i* と PLC の X/Y が 標準割付どおりに直結されたものとして動作します。
プログラムの動作確認だけをしたいときに使います。配線したケーブルは消えず、再び ON にすると戻ります。
