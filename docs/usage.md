# 操作方法

## 画面構成

```
┌──────────────┐                              ┌──────────────┐
│ 左パネル       │                              │ I/O モニタ     │
│ 接続/ワーク/   │        3D ビュー              │ 入力 16 点     │
│ 配線/課題 タブ │                              │ 出力 16 点     │
└──────────────┘                              └──────────────┘
                 [全体][正面][真上][端子台][配線][コンベア][操作部]
```

- **3D ビュー**: 作業盤と PLC（盤の奥）を表示します。
- **左パネル**: 4 つのタブで機能を切り替えます。最後に開いていたタブは次回も開きます。
- **I/O モニタ**: PLC 側から見た入出力の状態です。
- **視点ボタン**（画面下）: よく使う視点へカメラを移動します。
- **ヘルプ**（画面下の「？ ヘルプ」、または `F1` / `?` キー）: 操作方法の一覧を画面に表示します。初回起動時は自動で開きます（「起動時に表示しない」で止められます）。

## 3D ビューの操作

| 操作 | 動作 |
|---|---|
| 部品以外を左ドラッグ | 視点を回転 |
| 右ドラッグ | 視点を平行移動 |
| マウスホイール | ズーム |
| `←` `→` `↑` `↓` | 平行移動（←→: 左右、↑↓: 前後。押している間） |
| `Shift` + カーソルキー | 回転 |
| `Ctrl` + `↑` `↓` / `PageUp` `PageDown` | ズーム |
| 部品を左クリック | スイッチ操作（下表） |

| 部品 | 操作 |
|---|---|
| 電源スイッチ（CP1） | クリックで ON/OFF。OFF にすると盤の入出力がすべて止まります |
| 押しボタン PB1〜PB5 | 押している間だけ ON。**Shift+クリック**で押しっぱなし（ロック）／解除 |
| セレクタ SS0（手動・自動）、SS1（連続運転 切・入） | クリックで切替 |
| サムロータリスイッチ DSW | ▲ / ▼ をクリックで 0〜9 を増減 |
| ワークブロック | クリックで選択、左右にドラッグで移動 |

マウスカーソルが指の形になる場所が操作できる部品です。

## ファイル（保存・開く）

画面下の左端のボタン、またはキー操作で使います。

| 操作 | ボタン | キー |
|---|---|---|
| ファイルを開く | 開く | `Ctrl` + `O` |
| 上書き保存 | 保存 | `Ctrl` + `S` |
| 名前を付けて保存 | 名前を付けて保存 | `Ctrl` + `Shift` + `S` |

- ファイルは `*.sdojo`（JSON 形式のテキスト）です。
- **保存する内容**: 接続設定（通信方式・機種・IP・ポート・先頭デバイスなど）、配線練習用 PLC、配線モードのオン／オフ、配線（ケーブル）、ワーク（複数モード、置いたワークの位置とビス）。
- **保存しない内容**: スイッチの位置・DSW の値、試験タイマー、判定結果、PLC との接続状態。
- 開いているファイル名はウィンドウのタイトルと画面下に表示します。保存していない変更があると `*` が付き、アプリを閉じるときに「保存しますか？」と確認します。
- `SequenceDojo.exe` に `*.sdojo` ファイルをドラッグ＆ドロップして起動すると、そのファイルを開きます（アプリが起動済みの場合は、既存のウィンドウが前面に出るだけです）。
- ファイルを開いても PLC との接続は切り替わりません。接続中に開いた場合は「接続」を押し直すと新しい設定で接続します。
- ファイルとは別に、最後の接続設定や配線はアプリにも自動で記憶され、次回起動時に復元されます。

## 接続タブ

通信先 PLC の設定です。詳細は [plc-setup.md](plc-setup.md) を参照してください。

| 項目 | 説明 |
|---|---|
| 通信方式 | 三菱 MELSEC（SLMP）/ KEYENCE KV（上位リンク）/ Modbus TCP。切り替えるとポートと先頭デバイスが既定値になります |
| 機種 | MELSEC / KEYENCE の機種（Modbus では非表示） |
| シミュレータに接続 | iQ-R / iQ-L なら GX Simulator 3（127.0.0.1:5511）、KV-8000 / KV-X500 なら KV STUDIO シミュレータ（127.0.0.1:8501）に接続 |
| IP / ポート / 通信 | 接続先。通信（TCP / UDP）は MELSEC / KEYENCE のみ |
| Unit ID | Modbus TCP の Unit ID |
| 入力先頭 / 出力先頭 | 盤の入力 16 点を書き込む先頭、出力 16 点を読み出す先頭（例: `X0` / `Y0`、`MR000` / `MR100`、`C0` / `C16`） |
| 周期ms | 書込み・読出しの周期（既定 30） |

- 「接続」を押すと設定が保存され、次回も同じ値が入ります（保存先: `%LOCALAPPDATA%\SequenceDojo\WebView2`）。
- 状態バッジ: `未接続`（灰）／`接続中 NNms`（緑、NN は 1 周期の所要時間。マウスを乗せると接続先を表示）／`エラー`（赤、下にメッセージ）

## ワークタブ

- **ビス**: LS5・LS4・LS3・端 の 4 か所のビスの有無を選びます。選択中のワークがあれば、そのワークのビスが変わります。
- **品番**: LS3=1、LS4=2、LS5=4 の重みで合計した値を表示します（練習課題での品番の定義）。
- **左端に置く／中央に置く／右端に置く**: その位置にワークを置きます。すでにワークがある位置には置けません。
- **選択を取り除く／全部取り除く**

- **複数置けるようにする**: 通常は検定と同じくワークは 1 個で、置き直すと入れ替わります。オンにすると最大 4 個まで置けます（検定の範囲外の拡張）。オフに戻すと選択中のワーク以外は取り除かれます。この設定はアプリに記憶せず、**起動時は常にオフ**です（`*.sdojo` ファイルを開いたときは、ファイルの設定に従います）。

ワークはベルトの動きに合わせて流れ、端で止まります（ベルトは滑り続けます）。複数置いた場合、ワークは互いに重ならず押し詰まります。

## 配線タブ

3D 上でケーブル配線を行うモードです。詳細は [wiring.md](wiring.md) を参照してください。

- **配線モード** のチェックを入れると、配線したケーブルどおりに回路が計算されます。
  チェックを外すと、標準割付どおりに内部で結線されたものとして動きます（動作確認向け）。
- 端子を 2 つ順にクリックするとケーブルが 1 本つながります。`Esc` で選択を取り消します。
- ケーブルをクリックして選択し、`Delete` キー（または「選択ケーブル削除」）で外します。
- 配線は保存され、次回も残ります。

## 課題タブ

練習課題を選び、試験タイマーと自動判定を使って練習します。詳細は [tasks.md](tasks.md) を参照してください。

1. 課題を選んで仕様を読みます。
2. 「試験開始」でタイマーをスタートします（標準時間を過ぎると黄、打切り時間を過ぎると赤）。
3. 配線とプログラム作成を行い、PLC を RUN させます。
4. 「自動判定」を押すと、盤が自動で操作され、項目ごとに合否が表示されます。

自動判定中は盤のスイッチやワークが自動で操作されます。判定中は手を触れないでください。

## I/O モニタ

| 列 | 内容 |
|---|---|
| 通信先 | 通信先 PLC（接続タブで指定）のデバイス。入力先頭・出力先頭と機種から計算（iQ-F の X/Y は 8 進、その他は 16 進） |
| 端子 | 配線練習用 PLC（配線タブで指定）の端子名 |
| 接続先 | つながっている盤の機器 |

- 上の表が入力 16 点（PLC に書き込む値）、下の表が出力 16 点（PLC から読み出した値）です。
- 通信先と配線練習用 PLC は並び順（1〜16 点目）で対応します。例: 端子が FX5S の `X10`、通信先が iQ-R の `X8`。
- PLC 未接続のときは、**出力の行をクリック**すると手動で ON/OFF できます。PLC 無しで盤の動きを確かめるときに使います。

## 視点ボタン

| ボタン | 視点 |
|---|---|
| 全体 | 作業盤と PLC 全体 |
| 正面 | 操作者の目線 |
| 真上 | 真上から見下ろし |
| 端子台 | 盤の TB 端子台のアップ |
| 配線 | 端子台と PLC の間のケーブル |
| コンベア | コンベアとリミットスイッチ |
| 操作部 | ランプ・スイッチ・表示器 |
