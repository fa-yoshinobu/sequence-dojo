# 課題モード

## 使い方

1. 左パネルの「課題」タブで課題を選び、仕様を読みます。
2. 「試験開始」を押すとタイマーが動きます。「終了」で止まります。
3. 配線とプログラム作成を行い、PLC を RUN させます。
4. 「自動判定」を押すと、シナリオに沿って盤が自動で操作され、項目ごとの合否と合格数が表示されます。
   途中でやめるときは「判定中断」を押します。

### 試験タイマー

課題の `grade`（級）に応じて、製作等作業試験の時間を表示します。

| 級 | 標準時間 | 打切り時間 |
|---|---|---|
| 1 級 | 2 時間 10 分 | 2 時間 30 分 |
| 2 級 | 2 時間 | 2 時間 20 分 |
| 3 級 | 1 時間 35 分 | 1 時間 55 分 |

標準時間を過ぎると黄色、打切り時間を過ぎると赤色になります。
試験時間は変更されることがあります。最新の情報は公表資料で確認してください。

### 自動判定の注意

- 判定の最初に盤を初期状態（電源 ON、スイッチを戻す、ワークを撤去）に戻します。
- 判定は実時間で動きます。ウィンドウを最小化しても判定は続きます。
- PLC 未接続でも実行できますが、出力は手動操作のままなので、ほとんどの項目が不合格になります。

## 課題を追加する

1. `src/SequenceDojo/wwwroot/tasks/` に JSON ファイルを作ります。
2. `src/SequenceDojo/wwwroot/tasks/index.json` の配列にファイル名を追加します。
3. 画面で `F5` を押して再読み込みします（アプリの再起動は不要）。開発中は `src/SequenceDojo/wwwroot/tasks/` を編集した場合、`run.bat` で再ビルドすると `bin` 側にもコピーされます。

### ファイル形式

```json
{
  "title": "練習4 タイマ運転",
  "grade": 3,
  "description": "【仕様】\n1. PB1 を押すと右行を開始する。\n2. …",
  "scenario": [
    { "reset": true },
    { "work": { "at": "left", "screws": [0, 0, 0, 1] } },
    { "press": "PB1", "ms": 300 },
    { "waitFor": { "conveyor": "right" }, "timeout": 1000, "msg": "PB1 で右行開始" },
    { "waitFor": { "LS1": true }, "timeout": 8000, "msg": "右端に到達" },
    { "wait": 300 },
    { "expect": { "conveyor": "stop", "PL2": true }, "msg": "LS1 で停止し PL2 点灯" }
  ]
}
```

| キー | 内容 |
|---|---|
| `title` | 課題名（選択リストに表示） |
| `grade` | 級（1〜3）。タイマーの時間に使用 |
| `description` | 課題文。`\n` で改行 |
| `scenario` | 自動判定の手順（下記ステップの配列） |

### シナリオのステップ

1 ステップに 1 命令を書きます。上から順に実行されます。

**操作ステップ**

| ステップ | 動作 |
|---|---|
| `{ "reset": true }` | 盤を初期状態に戻す（電源 ON、PB 解放、SS0/SS1 = OFF、DSW = 0、ワーク撤去） |
| `{ "press": "PB1", "ms": 300 }` | PB を `ms` ミリ秒押して離す（`ms` 省略時 300） |
| `{ "hold": "PB5", "on": true }` | PB を押したままにする／`"on": false` で離す |
| `{ "ss0": true }` / `{ "ss1": false }` | セレクタを切り替える（`ss0`: true = 自動、`ss1`: true = 入） |
| `{ "dsw": 3 }` | DSW を 0〜9 に設定 |
| `{ "work": { "at": "left", "screws": [1, 0, 1, 1] } }` | ワークを置く。`at` は `left` / `center` / `right`。`screws` は LS5・LS4・LS3・端 の順に 1 = ビスあり |
| `{ "clearWorks": true }` | ワークを全部取り除く |
| `{ "wait": 500 }` | 指定ミリ秒待つ |
| `{ "note": "--- 自動運転 ---" }` | 結果一覧に見出しを出す（判定はしない） |

**判定ステップ**（合格数の対象。`msg` は結果一覧に出す説明で、省略可）

| ステップ | 判定内容 |
|---|---|
| `{ "expect": { … }, "msg": "…" }` | その時点で条件がすべて成り立っているか |
| `{ "waitFor": { … }, "timeout": 8000, "msg": "…" }` | `timeout` ミリ秒以内に条件が成り立つか（省略時 5000） |
| `{ "expectFor": { … }, "ms": 1000, "msg": "…" }` | `ms` ミリ秒の間、条件が成り立ち続けるか |

### 条件に使えるキー

| キー | 値 | 意味 |
|---|---|---|
| `PL1`〜`PL4` | true / false | 表示ランプ |
| `RY1`、`RY2` | true / false | リレーへの出力（TB20、TB21） |
| `DPL1`、`DPL2` | 0〜9、消灯は -1 | 7 セグ表示器の表示値 |
| `conveyor` | `"left"` / `"right"` / `"stop"` | コンベアの実際の動き（インターロック後） |
| `LS1`〜`LS5` | true / false | リミットスイッチ |

### 作成のコツ

- 最初に `reset` を入れ、必要な SS・DSW・ワークを設定してから操作します。
- ボタン操作の直後は PLC のスキャンと通信の遅れがあるため、`wait`（200〜300ms 程度）を入れるか `waitFor` を使います。
- コンベアで端から端まで移動するのに約 4 秒かかります。`waitFor` の `timeout` は 8000 程度にします。
- タイマ動作は `expectFor`（その間は変化しない）と `waitFor`（その後に変化する）を組み合わせて判定します。
