      作業盤の操作
      
      
      マウスカーソルが指の形になる場所が操作できる部品です。
      
      
      
        
      電源スイッチクリックで ON/OFF。OFF にすると盤の入出力がすべて止まります
      
        
      PB1〜PB5押している間だけ ON。Shift＋クリックで押しっぱなし（ロック）／解除
      
        
      PB5（非常停止）b 接点。押していないとき入力 ON、押すと OFF
      
        
      SS0 手動・自動クリックで切替（自動側で ON）
      
        
      SS1 連続運転クリックで切替（入側で ON）
      
        
      DSW▲ / ▼ をクリックで 0〜9 を増減（BCD で入力）
      
        
      ワーククリックで選択、左右にドラッグで移動
      
      
      
      
      コンベアは RY1 で左行、RY2 で右行。RY1 と RY2 はインターロックされ、先に ON した方が優先されます。

      ファイル（保存・開く）
      
      
        
        
      • 画面下の「保存」「名前を付けて保存」で、接続設定・配線練習用 PLC・配線・ワークを *.sdojo ファイルに保存します。「開く」で読み込みます。
        • 
        
      • 保存していない変更があると、ウィンドウのタイトルに * が付き、閉じるときに確認します。
        • 
        
      • スイッチの位置・試験タイマー・判定結果はファイルに含みません。

      接続タブ（通信先 PLC）
      
      
        
        
      1. 通信方式（三菱 MELSEC / KEYENCE KV / Modbus TCP）と機種を選びます。
        2. 
        
      2. IP・ポートを入力します。iQ-R / iQ-L の GX Simulator 3、KV-8000 / KV-X500 の KV STUDIO シミュレータは、チェックを入れるだけで接続先が設定されます。
        3. 
        
      3. 入力先頭・出力先頭は、方式を切り替えたときの既定値（X0 / Y0、MR000 / MR100、C0 / C16）のままでも使えます。
        4. 
        
      4. 「接続」を押し、バッジが 接続中 になれば完了です。
        5. 
      
      
      
      PLC が無くても、I/O モニタの出力の行をクリックすれば手動で ON/OFF できます。
      
    
      

    
      
      
      ワークタブ
      
      
        
        
      • ビス（LS5・LS4・LS3・端）の有無を選び、「左端／中央／右端に置く」でワークを置きます。
        • 
        
      • 品番は LS3＝1、LS4＝2、LS5＝4 の合計です。
        • 
        
      • 選択中のワークは、チェックでビスを変更できます。
        • 
        
      • 通常は検定と同じくワーク 1 個です。「複数置けるようにする」をオンにすると最大 4 個まで置けます（検定の範囲外）。
        • 
        
      • 左端では LS2〜LS5、右端では LS1 が、ビスがあると ON になります。
        • 
      
      
    
      

    
      
      
      配線タブ
      
      
        
        
      • 「配線練習用 PLC」で 3D の PLC の機種（FX5S / FX5U / Q / iQ-R）を選べます。通信先 PLC（接続タブ）とは別に指定できます。
        • 
        
      • 「配線モード」を ON にすると、ケーブルどおりに回路が計算されます。OFF のときは標準割付で内部結線されたものとして動きます。
        • 
        
      • 端子を 2 つ順にクリックすると配線できます。Esc で選択を取り消します。
        • 
        
      • ケーブルをクリックで選択し、Delete で削除します。
        • 
        
      • 「配線チェック」で短絡・コモン未配線・未配線端子などを確認できます。
        • 
        
      • 「標準配線を自動作成」で標準割付どおりの配線を一度に作れます。
        • 
      
      
      
      
        
      入力コモンS/S（Q / iQ-R は COM）に +24V（盤の TB+）。サービス電源の 24V を使う場合は、PLC の 0V と盤の TB− も配線
      
        
      出力コモンCOM0〜COM3 を盤の 0V（TB−）へ
      
        
      ケーブルの色+24V　0V・COM　入力　出力
      
      
      
    
      

    
      
      
      課題タブ
      
      
        
        
      1. 課題を選び、仕様を読みます。
        2. 
        
      2. 「試験開始」でタイマーを開始します（標準時間を超えると黄、打切り時間を超えると赤）。
        3. 
        
      3. 配線とプログラム作成を行い、PLC を RUN させます。
        4. 
        
      4. 「自動判定」で盤が自動操作され、項目ごとに合否が出ます。判定中は盤に触れないでください。
        5. 
      
      
    
      

    
      
      
      I/O モニタ
      
      
        
        
      • 「通信先」は通信先 PLC のデバイス、「端子」は配線練習用 PLC の端子名、「接続先」はつながっている盤の機器です。
        • 
        
      • 入出力は並び順（1〜16 点目）で対応します。例: 配線は FX5S の X0〜X17、通信先は iQ-R の X0〜XF。
        • 
        
      • PLC 未接続のときは、Y の行をクリックして手動で ON/OFF できます。
        •
